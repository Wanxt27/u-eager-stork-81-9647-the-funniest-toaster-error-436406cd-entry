A [make.fun](https://make.fun) entry for **The Funniest Toaster Error** — write the
funniest error message a kitchen toaster would show its owner, in 120 characters
or fewer.

`main.ts` writes a single deadpan line to `/output/entry.txt`:

> ERROR: Toasting failed. The bread left me for a microwave. I understand.

Run it with Node 22:

```sh
node main.ts
```
